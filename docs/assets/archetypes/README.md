# Archetype Icons

This directory contains icon assets for the three officer archetypes:
- `berserker.png` - Berserker archetype icon
- `archer.png` - Archer archetype icon  
- `trapper.png` - Trapper archetype icon

## Current Status

The current PNG files are placeholder images (colored squares). They should be replaced with the actual pixel art icons from the GitHub issue:

- Berserker icon: https://github.com/user-attachments/assets/27297f16-ea8f-45e6-8cb7-c17c0440f4c3
- Archer icon: https://github.com/user-attachments/assets/2b9aa9a0-fb07-46ed-87af-6e50ad1eb501
- Trapper icon: https://github.com/user-attachments/assets/66f53973-e68c-4f85-96ff-b5dd1943fc3f

## Usage

These icons are automatically displayed on officer cards in Spectate mode, showing the archetype of each officer visually.

The icons are copied to the build output by the `copy-archetypes.mjs` script during development and build processes.
